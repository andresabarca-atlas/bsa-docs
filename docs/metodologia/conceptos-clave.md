# Conceptos clave

| Concepto | Definición operativa |
|---|---|
| Amenaza | Fenómeno con capacidad de causar daños, representado mediante una intensidad espacial. |
| Exposición | Activos viales localizados y caracterizados que pueden resultar afectados. |
| Vulnerabilidad | Relación entre intensidad y daño físico esperado o tiempo de interrupción. |
| Criticidad | Consecuencia funcional y económica de interrumpir un tramo de la red. |
| Riesgo | Consecuencia económica esperada considerando severidad y probabilidad. |
| Período de retorno, `TR` | Inverso de la probabilidad anual de excedencia: `p = 1/TR`. |
| RMD | Relación media de daño, expresada en el CSV como porcentaje de 0 a 100. |
| DAE | Daño anual esperado por daño físico y reposición. |
| PAE | Pérdida anual esperada por interrupción del tránsito. |
| Prioridad | Suma monetaria anual `DAE_total + PAE_total`. |

DAE y PAE describen consecuencias distintas y se conservan por separado antes de su suma. El BSA 2.0 actual no reporta PML como producto del cálculo.

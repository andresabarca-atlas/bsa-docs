    Results by Country¶

    BSA 2.0 has been implemented in three countries in Latin America and the Caribbean. Each country has its own online dashboard, accessible from any browser. The results reflect the hazard, exposure, vulnerability, and criticality conditions of the national road network, calculated using the specific input data for each context.

    Development stage

    The Dominican Republic is the project's reference case, with consolidated results. The Costa Rica and El Salvador dashboards correspond to preliminary versions in the process of validation.

    Dominican Republic¶

    BSA 2.0 development reference case.

    The implementation in the Dominican Republic was the first production deployment of BSA 2.0. It includes evaluation of the national road network against fluvial flooding, coastal flooding, tsunami, and earthquake hazards. Monetary values are expressed in Dominican pesos (DOP).

    Open Dominican Republic dashboard

    Costa Rica¶

    Preliminary implementation.

    The implementation in Costa Rica applies the BSA 2.0 methodology to the Costa Rican road network, with emphasis on flooding and earthquake hazards. Monetary values are expressed in Costa Rican colones (CRC).

    Open Costa Rica dashboard

    El Salvador¶

    Preliminary implementation.

    The implementation in El Salvador analyzes the national road network with emphasis on seismic and hydrological hazards. Monetary values are expressed in US dollars (USD).

    Open El Salvador dashboard

    Cross-country comparability

    Prioritization rankings and EAD/EAL values are country-specific and are not directly comparable between countries, due to differences in the extent of the analyzed network, the universe of evaluated hazards, unit infrastructure prices, and transit values used in each context.

    Access and technical requirements¶

    The dashboards are ArcGIS Experience Builder web applications and require no software installation. It is recommended to use:

    • An updated browser (Chrome, Firefox, Edge).
    • A stable internet connection to load cartographic layers.
    • For access to advanced ArcGIS Online functions, an IDB institutional account may be required.
